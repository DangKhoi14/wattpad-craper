# Wattpad Chapter Scraper

A two-script toolkit to extract chapter lists and download chapter content from Wattpad stories into local `.txt` files.

---

## Project Structure

```
.
├── get_code_list.py      # Step 1: Extract chapter codes from a story's table of contents
├── wattpad_scraper.py    # Step 2: Download chapter content using extracted codes
├── chapters.txt          # Generated by get_code_list.py — input for wattpad_scraper.py
└── wattpad_chapters/     # Output directory — one .txt file per chapter
```

---

## Requirements

```bash
pip install cloudscraper beautifulsoup4 requests
```

| Package | Purpose |
|---|---|
| `requests` | Used in `get_code_list.py` to fetch the table of contents |
| `cloudscraper` | Used in `wattpad_scraper.py` to bypass Cloudflare protection |
| `beautifulsoup4` | HTML parsing in both scripts |

---

## Workflow

### Step 1 — Extract Chapter Codes

Edit the `url` variable in `get_code_list.py` to point to your target story's table of contents page:

```python
url = "https://www.wattpad.com/<story-id>-<story-slug>"
```

Then run:

```bash
python get_code_list.py
```

This will:
- Fetch the story's table of contents
- Extract numeric chapter codes and titles from each entry
- Write all codes to `chapters.txt`, one per line

Example `chapters.txt` output:
```
1404698831
1404698832
1404698833
```

---

### Step 2 — Download Chapter Content

```bash
python wattpad_scraper.py
```

This will:
- Read chapter codes from `chapters.txt`
- For each code, fetch `https://www.wattpad.com/<code>`
- Handle internal pagination (`page/2`, `page/3`, ...) automatically
- Extract chapter title from the page `<header>` and use it as the filename
- Save content to `wattpad_chapters/<title>.txt`

---

## Configuration

Both scripts expose configuration at the top of the file:

| Variable | File | Default | Description |
|---|---|---|---|
| `OUTPUT_DIR` | `wattpad_scraper.py` | `wattpad_chapters` | Output folder for `.txt` files |
| `MAX_RETRIES` | `wattpad_scraper.py` | `3` | Max retry attempts per page (overridden to `5` inside `fetch_with_retry`) |
| `times` | `wattpad_scraper.py` | `None` | Limit number of chapters to process; `None` means no limit |

To process only the first N chapters, set `times` in `__main__`:

```python
times = 5  # process only 5 chapters
```

---

## Anti-Bot Behavior

`wattpad_scraper.py` uses several strategies to avoid detection:

- **`cloudscraper`** — handles Cloudflare JS challenges automatically
- **Random delays** — waits 3–7 seconds between page requests
- **Extended wait on 403** — waits 20 seconds if Cloudflare blocks a request
- **Retry logic** — retries up to 5 times on connection failures with random backoff
- **Chrome headers** — spoofs a real Chrome browser on Windows

---

## Output

Each chapter is saved as a `.txt` file named after the chapter title extracted from the page header:

```
wattpad_chapters/
├── Chapter 865. Chỗ trống nhà ngươi để lại là quá lớn. (5).txt
├── Chapter 866. ...txt
└── ...
```

- Filename is sanitized (forbidden characters removed, max 100 characters)
- Fallback: if the header title cannot be found, the first line of the content is used
- Encoding: UTF-8

---

## Known Limitations

- Wattpad may return `403` if requests are made too frequently — increase sleep delays if this occurs
- Content is extracted from `<pre>` tags; stories using a different HTML structure may require changes to `extract_text_from_pre()`
- The next-chapter link relies on `<a class="next-part-link">` or `<a class="continue-link">`; Wattpad UI changes may break this
- `get_code_list.py` uses plain `requests` without Cloudflare bypass — it may fail on protected story pages; replace with `cloudscraper` if needed
